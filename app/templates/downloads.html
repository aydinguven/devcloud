📖 Master Sunucu Kurulum Kılavuzu

İndirilen paketi aynı dağıtım ailesindeki Rocky Linux 10.x veya RHEL 10.x x86_64 hedefe aktardıktan sonra aşağıdaki adımları uygulayın.

Adım 1

Bütünlük Doğrulaması (SHA-256 Checksum)

Dosya aktarımı sırasında bozulma veya eksiklik olmadığını doğrulamak için paketin yanındaki .sha256 dosyasıyla kontrol edin: 

sha256sum -c devcloud-offline-*.tar.gz.sha256
✓ Çıktıda ...: OK mesajını görmelisiniz.
Adım 2

Arşivi Açma ve Dizine Geçiş

Tarball arşivini açın ve oluşturulan devcloud klasörüne geçin: 

tar -xzf devcloud-offline-*.tar.gz
cd devcloud
Adım 3

Dağıtım Profilini Kontrol Etme

Paket Rocky ve RHEL için ayrı RPM seti taşır. Hedef dağıtım ve mimariyi kontrol edin: 

source /etc/os-release
echo "$ID $VERSION_ID $(uname -m)"
Adım 4

Otomatik Kurulumu Başlatma

Script eksik Podman/Python RPM'lerini çevrim dışı kurar, 5 image'ı yükler, manifesti doğrular ve systemd servisini başlatır: 

sudo bash deploy/deploy_offline.sh
Tamamlandı

DevCloud Web Arayüzüne Giriş

Tarayıcınızdan sunucu IP adresine bağlanarak ilk yönetici hesabınızı oluşturabilir ve geliştirme ortamlarınızı kullanmaya başlayabilirsiniz: 

http://<SUNUCU-IP-ADRESI>/

🧭 CPU Worker Kurulum Kılavuzu

Önce master yönetim panelinden worker node oluşturun ve yalnızca bir kez gösterilen node token'ını güvenli şekilde kaydedin.

{% if worker_bootstrap_url %}

Hızlı kurulum — tek komut

curl -fsSL '{{ worker_bootstrap_url }}' | sudo bash
Script güncel Worker arşivini ve checksum dosyasını bu Master'dan indirir. Node ID ile token'ı komut satırına yazmadan terminalden ister.
{% endif %}

Manuel seçenek: paketi doğrulayın ve açın

sha256sum -c devcloud-worker-offline-*.tar.gz.sha256
tar -xzf devcloud-worker-offline-*.tar.gz
cd devcloud-worker

2. Worker kimlik bilgilerini hazırlayın

sudo install -d -m 0755 /etc/devcloud
sudo install -m 0600 deploy/worker.env.example /etc/devcloud/worker.env
sudo vi /etc/devcloud/worker.env
Master URL, node ID ve node token alanlarını yönetim panelindeki değerlerle doldurun.

3. Worker'ı kurun

sudo bash deploy/deploy_worker_offline.sh
sudo journalctl -u devcloud-worker -f
Kurucu eksik Podman, Python ve subscription-manager RPM'lerini yerel paketten yükler. Worker yalnızca master'a doğru HTTPS/WSS bağlantısı açar; inbound yönetim portu gerekmez.
